## 찍는 법(에뮬레이터, debug 빌드)

1. 개발 PC 서버를 켠다(`chargecheck/server`, 포트 8000).
2. 차 위치 근처 충전소에 다른 차들의 실패 기록을 넣는다(충전기마다 서로 다른 기기 2건이면 빨강).
3. 앱의 개발용 버튼: [목적지] → 내비 안내 시작 → 앱으로 돌아와 [내비가](내비가 충전소 경유) → 팝업 → [바꾸기].
