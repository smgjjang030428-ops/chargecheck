# 2분 30초 구성과 내레이션

목표: 차량 SOC로 충전 결과를 확인하고, 다음 운전자가 주의 충전소를 피하도록 돕는 흐름을 보여 줍니다.

아래 길이는 편집 제안입니다. 앱 내부의 몇 분 대기를 영상에서 잘라낼 수 있으며, 시간 압축·가짜 데이터 사용 장면은 표시합니다.

| 구간 | 화면·촬영할 행동 | 내레이션 |
|---|---|---|
| 00:00–00:12 | 앱 이름 + 충전소에 도착했지만 충전하지 못하는 문제를 짧은 자막으로 소개 | “충전소에 도착했는데 충전이 되지 않는다면, 다른 곳을 다시 찾아야 합니다. 차지체크는 차량의 충전 결과를 모아 다음 운전자의 헛걸음을 줄입니다.” |
| 00:12–00:30 | 실제 release의 새 첫 화면. 상황카드와 보조 지도, 핀 묶음·상세 선택 | “평소처럼 기본 내비에 목적지를 설정하면 됩니다. 차지체크는 그 충전소의 최근 확인 근거와 주의 정보를 살펴봅니다.” |
| 00:30–00:55 | demo LIVE 정상. 도착 → SOC 상승 → 정상 기록. 대기 구간 편집 | “차량 배터리 잔량이 실제로 오르면 충전 성공을 자동으로 기록합니다. 단순히 도착했다는 이유로 성공 처리하지 않습니다.” |
| 00:55–01:20 | demo LIVE 고장 시나리오. SOC 그대로 → 질문 → 직접 [응, 안 돼요] → 실패 기록 | “잔량이 그대로라고 바로 고장으로 단정하지 않습니다. 정차 중 운전자에게 확인하고, 충전이 안 됐다는 답을 받았을 때 실패를 기록합니다.” |
| 01:20–01:55 | 최신 실제 내비 연동을 새로 녹화. 주의 충전소가 경로에 있음 → 경고 → [대안으로 바꾸기] → 내비 반영 확인 | “같은 충전소로 향하는 다음 차에는 도착 전에 알려 줍니다. 운영사 점검 정보와 차량 실패 제보를 구분하고, 대안으로 바꾼 뒤 내비에 반영됐는지 확인합니다.” |
| 01:55–02:15 | 근거 문구 확대. 운영사 정보/차량 제보 구분, 주행 질문 보류를 짧은 자막으로 설명 | “주행 중에는 필요한 카드 한 장을 우선합니다. 출발 시 보류한 실패 확인은 다음 주차 때 묻고, 답이 없으면 실패로 기록하지 않습니다.” |
| 02:15–02:30 | 새 첫 화면 + 앱명·팀명 | “차지체크. 차량에서 확인한 충전 결과를, 다음 운전자의 판단에 연결합니다.” |

## 현재 바로 사용할 수 있는 이미지

- 도입·마무리: `02_최신_화면/01_release_상황카드와_보조지도.png`
- 시연 모드 소개: `02_최신_화면/02_demo_시나리오_선택화면.png`
- 차량 실패 제보의 문구 설명: `02_최신_화면/03_demo_실패제보와_대안카드.png`

과거 실제 내비 교체 장면은 `04_이전_캡처_참고용/기존_시연영상_자료`에 있습니다. 이 파일은 촬영 구도 참고용으로 사용하고, 최신 동작을 보여 주는 구간은 새로 녹화합니다.

## 녹화 시간이 부족할 때

실제 내비 교체 촬영을 끝내지 못하면 demo의 마지막 시나리오로 경고·대안 변경을 보여 주고 “가짜 차량 데이터 · 시나리오 재생”을 계속 표시합니다. 이 장면을 실제 Pleos 내비 연동 결과로 소개하지 않습니다.
