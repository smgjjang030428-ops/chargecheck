# 편집용 자막 문구

아래 문구를 장면에 맞춰 사용합니다. 화면에서 확인할 수 있는 사실에 맞춰 선택합니다.

## 핵심 소개

- 차량 SOC로 확인하는 충전 결과
- 도착만으로 성공 처리하지 않아요
- 충전 실패는 운전자 확인 후 기록
- 내비가 고른 충전소, 도착 전에 확인
- 대안으로 바꾼 뒤 내비 반영까지 확인
- 기본 내비와 함께 쓰는 차지체크

## 근거 구분

- 차량 SOC로 충전 확인
- 운영사 충전 중 확인
- 운영사 점검·운영 중지
- 차량 충전 실패 제보
- 미확인: 최근 확인 기록 없음
- 최근 충전 확인은 현재 빈자리나 충전 성공을 보장하지 않습니다

## 개입 방식

- 주행 중 필요한 카드 한 장
- 출발 시 실패 확인은 다음 주차로 보류
- 무응답은 실패로 기록하지 않아요
- 다른 경유지와 목적지는 유지

## 장면 표시

- 가짜 차량 데이터 · 시나리오 재생
- 시연 데이터 · 시간 압축
- Pleos Connect 에뮬레이터에서 촬영
- 개발용 로컬 서버 데이터

자동으로 재생된 YES를 “답이 없어 실패 처리”로 설명하거나, 운영사 중지를 “차량 여러 대의 실패 제보”로 설명하지 않습니다.
