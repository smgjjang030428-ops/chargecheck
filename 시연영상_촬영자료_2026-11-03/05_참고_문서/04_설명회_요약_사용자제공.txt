1. 공모전 개요
이번 공모전은 현대자동차·기아·제네시스 차량의 운전자와 탑승자를 위한 차량용 앱을 직접 개발하고 출품하는 공모전이다. 차량 사용자마다 다른 라이프스타일과 이동 상황을 고려하여, 스마트폰 앱을 차량 화면에 단순히 옮기는 것과 다른 차량 특화 경험을 만드는 것이 목적이다.
- 접수 기간: 2026년 10월 21일 ~ 11월 15일
- 참가 방식: 개인 또는 최대 5인 팀
- 참가 부문: 대학생 부문 / 일반 부문
- 공모 분야: 제한 없음. 모빌리티, 라이프스타일, 엔터테인먼트, 안전, 동승자 케어 등
- 1차 지원: 개발이 완성되지 않았어도 기획서로 지원 가능
- 2차 PT: 실제 동작하는 앱 개발 완료 및 현장 시연 필수

3. 참가 자격 및 복수 출품
- 대학생 부문에는 대학원생도 포함된다.
- 팀원 모두 대학생(대학원생 포함)이어야 대학생 부문에 지원할 수 있다.
- 팀원 중 일반인이 한 명이라도 포함된 혼합팀은 일반 부문으로 지원한다.
- 대학생이면서 스타트업을 운영하는 경우 대학생 부문으로 지원 가능하다고 답변했다.
- 서로 다른 작품의 복수 출품은 가능하며 출품 개수 제한이 없다.
- 외국인 및 고등학생·미성년자의 참가 조건은 운영 사무국이 별도로 확인·공지한다고 안내했다.
- 현대자동차그룹 임직원 및 그룹사 관계자는 참가할 수 있으나, 최종 시상 및 상금 수여 대상에서는 제외된다고 답변했다.

7. PLEOS 개발 플랫폼 개요
PLEOS Playground
현대자동차그룹의 소프트웨어 중심 모빌리티 플랫폼 PLEOS를 위한 개발자 포털이다. 플랫폼 소개, 개발 가이드, SDK·API 문서, 테스트 도구, 앱 등록 관련 안내 등을 제공한다.
PLEOS Connect
- 현대자동차·기아·제네시스 차량의 차세대 인포테인먼트 플랫폼.
- Android Automotive OS(AAOS) 기반.
- 기존 Android 개발 방식과 유사하지만 차량의 주행·정차 상태, 차량 정보, 운전자·동승자 사용 환경을 고려해야 한다.
PLEOS App Market
차량용 앱을 사용자에게 배포하기 위한 앱 유통 플랫폼. 공모전에서 개발하는 앱도 차량 특화 기능과 사용자 경험의 결합이 중요하다.
개발 흐름
1. 차량 이용자의 문제와 필요한 경험을 정의한다.
2. 해결에 필요한 차량 정보·기능을 선택한다.
3. Android 개발 환경을 구성한다.
4. PLEOS SDK·API를 연동해 기능을 구현한다.
5. 에뮬레이터와 Virtual Console로 테스트한다.
6. 앱 배포·등록 관련 사항을 확인한다.
8. 설명회에서 소개한 SDK 및 기능
SDK / 기술	소개된 활용 범위

NaviHelper SDK	목적지 설정, 경유지 관리, 경로 요청, 내비게이션 관련 정보 조회

Fused Location SDK	차량 위치 정보 활용

- SDK를 많이 사용하는 것 자체가 목표는 아님. 앱의 핵심 문제를 해결하는 데 필요한 SDK를 적절히 활용하는 것이 중요하다.
- SDK별 구체적인 메서드, 접근 가능한 데이터, 지원 조건은 개별 개발 문서에서 확인해야 한다.
- 발표자는 공모전 참가자에게 현재 공개되지 않은 SDK도 제공할 예정이라고 언급했으나, 제공 시점과 구체적인 범위는 스크립트만으로 확인되지 않는다.
개발 환경
- Android Studio 사용.
- 개발 언어: Java 또는 Kotlin.
- 설명회에서 소개된 가이드의 요구 사항: Android API 28 이상, Gradle 8.0 이상.
- 개발 문서의 Getting Started에서 프로젝트 생성, 에뮬레이터 구성, SDK 연동, 최초 차량 API 호출 예제를 확인하도록 권장.
SDK 권한
- 공모전 개발·에뮬레이터 테스트 단계에서는 설명회에서 언급한 SDK 사용에 대해 별도 사전 승인 절차가 불필요하다고 안내했다.
- 다만 AndroidManifest에 SDK 문서에서 요구하는 uses-permission 선언이 필요하다.
- 실제 앱 마켓 배포 시에는 사용 권한에 대한 심사가 적용된다. 승인되지 않은 권한을 선언하면 심사를 통과하지 못할 수 있다.
9. 에뮬레이터·Virtual Console·시연
- PLEOS Connect Emulator: 실제 차량 없이 Android Studio에서 차량용 앱을 실행하고 SDK 연동 기능을 검증하는 가상 환경.
- Virtual Console: 기어 상태, 도어 열림·닫힘, 배터리·충전 상태 등 가상 차량 조건을 변경하여 앱 반응을 확인하는 테스트 도구.
- 예: 배터리 값을 변경하고 앱 화면이나 안내가 변경된 값을 정상적으로 반영하는지 시험한다.
- 2차 PT에서 실제 차량 시연은 지원하지 않는다고 공식 Q&A에서 답변했다.
- 앱 검증과 시연 준비는 PLEOS Playground에서 제공하는 에뮬레이터를 기준으로 진행한다.
- 따라서 초기 개발부터 에뮬레이터에서 핵심 기능 하나가 실제로 동작하도록 만드는 것을 권장했다.
10. 주요 Q&A
Q. 생성형 AI를 이용하여 기획서를 쓰거나 앱을 개발해도 되는가?
A. 가능하다. 기획과 개발 전 과정에서 생성형 AI 보조 도구를 활용할 수 있다. 다만 참가자가 앱의 전체 구조와 로직을 이해하고 2차 PT 기술 질의응답에서 직접 설명할 수 있어야 한다.
Q. 1인·1팀이 여러 기획서를 제출할 수 있는가?
A. 가능하다. 출품 수 제한이 없다. 서로 다른 프로젝트는 이름으로 구분해 제출한다.
Q. 2차 PT에서 실제 차량으로 시연하는가?
A. 아니다. 실차 시연은 지원하지 않으며 에뮬레이터를 활용한다.
Q. 외부 API와 인터넷을 사용할 수 있는가?
A. 가능하다. 외부 API 결합과 공개 네트워크 연결이 가능하다고 답변했다.
Q. SDK를 이용하려면 사전 승인이 필요한가?
A. 공모전 개발·에뮬레이터 테스트 단계에는 별도 승인 없이 필요한 권한 선언으로 사용할 수 있다. 실제 앱 마켓 배포 심사 시에는 승인된 권한 여부를 확인한다.
Q. 대학생이면서 스타트업을 운영하면 어느 부문에 지원하는가?
A. 대학생 부문으로 지원할 수 있다고 답변했다.
Q. 개발 관련 세부 사항은 어디에 문의하는가?
A. 운영 사무국의 안내 이메일로 질문할 수 있으며, 다수 질문은 홈페이지 FAQ로 정리할 예정이라고 안내했다. 정확한 이메일 주소는 이 스크립트에 포함되어 있지 않다.
