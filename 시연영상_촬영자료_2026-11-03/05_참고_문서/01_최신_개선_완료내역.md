# ChargeCheck 개선 완료 내역

- 기준일: 2026-11-02
- 대상: 현재 Android 앱 소스, 실제 기기용 release APK, 시연용 demo APK
- 선정 방향: 내비 연동 상황카드 중심 + 주차 중 보조 지도

## 반영한 내용

| 항목 | 최종 동작 |
|---|---|
| U1 근거 문구 | 운영사 점검·운영 중지 / 차량 실패 제보 / 차량 SOC 충전 확인 / 운영사 충전 중 확인을 구분한다. 화면·주행 카드·알림은 공통 문구 함수를 사용한다. 과거 성공 시각을 실패 시각으로 표시하지 않는다. |
| U2 알림 한 장 | 도착 전 경고 → 충전 필요 → 정차 중 확인·질문·충전기 번호 → 짧은 안내 중 하나를 선택하고 나머지 알림 ID를 취소한다. |
| U3 첫 화면 | 현재 내비 충전소의 이름·판정·근거와 대안을 먼저 표시한다. 내비 충전소가 없으면 자동 확인 안내와 주변 최근 확인 기록 3곳을 표시한다. 지역 집계는 작은 보조 정보로 내린다. |
| U4 지도 | 가까운 핀은 개수로 묶고 확대하면 펼친다. 같은 좌표이거나 최대 확대에서도 겹치면 목록으로 선택한다. 선택·내비 충전소·대안은 이름 표식을 붙이며, 상태는 색과 ✓/!/? 표식을 함께 사용한다. |
| U5 질문 시점 | 실제 앱은 출발 시 실패 확인을 숨겨 보관하고, 2시간 안의 다음 주차 때 한 번 묻는다. 미응답·아니요는 실패로 기록하지 않는다. 주행 화면과 알림에서는 기록 수집 질문을 숨긴다. |
| B1 경유지 보존 | 다른 경유지의 좌표를 모르면 변경을 거절한다. 좌표 없는 경유지를 조용히 삭제하지 않는다. |
| B2 이전 경로 정리 | 충전소 없는 새 경로와 명시적 안내 취소는 이전 경고·재시도·판정을 정리한다. 재탐색 중 잠깐 빈 경로는 유지한다. |
| B3 반영 실패 복구 | 내비 변경 요청 실패·반영 확인 시간 초과 뒤 현재 경로를 확인한다. 원래 충전소가 남아 있을 때 경고를 복구한다. 늦게 반영된 경로에는 중복 변경을 하지 않는다. |

추가로 큰 제목의 줄 간격 겹침, 좁은 카드의 버튼 줄바꿈, 중복 시스템 제목 표시를 수정했다. 충전기 상세에서 운영 중지를 차량 실패 0건으로 표시하던 문구도 제거했다. README와 앱 구동 기획의 현재 동작 설명을 갱신했다.
