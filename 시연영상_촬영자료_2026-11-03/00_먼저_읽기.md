## 어떤 APK를 쓰나

- `ChargeCheck_real_release.apk`: 최신 실제 앱 UI·Pleos 연동 촬영. 배포 서버를 사용합니다.
- `ChargeCheck_demo_debug.apk`: 인터넷 서버 없이 SOC 상승·실패 확인·대안 변경을 반복 재현합니다. 가짜 차량 데이터임을 화면 또는 자막으로 표시합니다.
- `ChargeCheck_real_debug_로컬서버용.apk`: 개발 버튼·판단 기록을 사용한 연동 촬영. PC의 로컬 서버가 필요합니다. 실제 release와 같은 패키지이므로 둘 중 하나를 선택해 설치합니다.

## 자료 상태

최신 PNG 캡처 3장과 기존 시연·스크린샷 자료를 모았습니다. 이전 자료의 설명 문서도 함께 보관했습니다. 기존 캡처에는 예전 화면, 운영사 중지를 실패 기록으로 부르던 문구, 출발 직후 실패 확인 화면이 포함됩니다. 최신 영상에 해당 장면을 쓰려면 현재 APK로 다시 촬영합니다.

완성 영상은 `07_최종_편집본/ChargeCheck_시연영상_한국어음성_1080p_2026-11-03.mp4`입니다. 실제 release 첫 화면과 가짜 데이터 시연을 구분해 표시했으며, 한국어 합성음성과 자막을 넣었습니다. 2차 편집에서 도착 전 경고→대안으로 바꾸기 구간을 실제 release·배포 서버·Pleos 기본 내비 녹화로 교체했습니다(목적지 교체. 경유지 교체 장면은 없음).

참고 문서에 적힌 소스 경로·상대 링크는 원래 프로젝트를 기준으로 합니다. 촬영자료 안에서는 이 안내의 폴더 경로를 따라가면 됩니다.

2분 30초는 편집용 구성 제안입니다. 공식 제출 영상의 길이 제한을 뜻하지 않습니다.
